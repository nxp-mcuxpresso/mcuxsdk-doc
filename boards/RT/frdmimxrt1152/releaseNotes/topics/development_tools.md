# Development tools

The MCUXpresso SDK was tested with following development tools. Same versions or above are recommended.

IAR Embedded Workbench 9.70.4 does not currently support the MIMXRT1152 device. To build a project for MIMXRT1152 using IAR 9.70.4, install the corresponding IAR patch.

Segger J-Link does not currently support MIMXRT1152. To use J-Link with this device, install the corresponding J-Link patch.

The IAR and J-Link patches are distributed via the [iar_segger_support_patch_rt1150](https://mcuxpresso.nxp.com/dashboard?download=9b8e56aa2cee1514784871e8aafd5647).
