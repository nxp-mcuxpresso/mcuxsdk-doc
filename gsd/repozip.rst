The Repository-Layout SDK Package is downloaded and extracted the same way as the
Classic SDK Package — see :doc:`SDK Builder </gsd/install/sdk_builder>` for how to
obtain it. Once extracted, it uses the same SDK workspace layout as the GitHub
Repository SDK, so you get the same offline development experience as a full workspace
checkout. This section walks through installing development tools, touring the
workspace layout, building your first example, generating IDE projects for IAR or Keil
MDK, and importing the package into the MCUXpresso for VS Code extension.
