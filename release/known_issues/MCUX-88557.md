# Apps utilizing ELE HSE-B may need to disable flash data prefetching in some cases
## Summary
The ELE HSE-B module requires data cache to be disabled for correct functionality. Due to this, the ERR052645 errata may manifest itself in some cases. An issue was identified on ARMGCC release targets (high optimization enabled) for the el2go and mbedtls3x examples that causes failures in software execution.
## Workaround
To work around the issue, whenever the D-cache is disabled, please disable flash data prefetching as well. The following code snipped may be applied:
```C
/* Disable flash prefetch; see the ERR052645 errata for more information */
PFLASH->PFCR[0] &= ~(PFLASH_PFCR_P0_DPFEN_MASK);
PFLASH->PFCR[1] &= ~(PFLASH_PFCR_P1_DPFEN_MASK);
```
